# Timewise

Screen time for Windows. Timewise runs in the tray and records how long you spend in each app. It shows your usage by day, week or month, with charts, a timeline, categories and daily app limits.

## Install

1. Open **[Releases](https://github.com/zw7z/Timewise-Releases/releases/latest)** and download `Timewise_Setup.exe`.
2. Run it. Windows may show **"Windows protected your PC"**, because the installer isn't signed yet. Click **More info → Run anyway**.
3. It installs for your user only, so it needs no admin permission and no extra downloads. .NET is included.

## Updates

The app updates itself: **Settings › About & updates › Check for updates**. It also checks quietly once a day. Updating never touches your history, which stays in `%LOCALAPPDATA%\Timewise`.
